Windows installation: the API, the console and the worker run as Windows services (`scripts/Install-WindowsServices.ps1` registers them under per-service virtual accounts or a chosen account, configures them through their environment, runs the migrations, verifies `/health/ready` and a stop/start), or the API and the console under IIS in-process with the worker still a service; the connection is integrated authentication on the service account or an encrypted SQL login; `scripts/Install-SqlExpress.ps1` downloads Microsoft's Express installer at install time (or takes a pre-downloaded package), installs the `WMS` instance with Windows authentication and TCP on localhost, and `scripts/Provision-WmsDatabase.ps1` provisions the database with migration and runtime logins (or emits the T-SQL for a DBA). docs/INSTALL-WINDOWS.md.
