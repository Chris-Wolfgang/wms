# HTTP API contract

The API's endpoints, requests and responses are described by an OpenAPI 3 document generated from the
product. It is the contract client code is built against; each version of this site carries the document
for that release.

- <a href="../http-api/openapi-v0.json">openapi-v0.json</a>: version 0 of the HTTP API (`/api/v0/...`).

Open it in any OpenAPI viewer or generate a client from it. A running server also serves the same document
at `/openapi/v0.json`.

The **API Reference** section of this site is the .NET library reference (types and members), generated
from the source code; this page is the HTTP contract.
